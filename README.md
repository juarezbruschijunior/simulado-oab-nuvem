# ☁️ Simulado OAB Pro - Servidor em Nuvem de Questões

Este repositório atua como o servidor oficial de distribuição de dados em nuvem (Over-The-Air / OTA) para o aplicativo **Simulado OAB Pro**.

## 📡 Endpoints de Acesso:
* **Banco de Questões:** [questoes_nuvem.json](https://raw.githubusercontent.com/juarezbruschijunior/simulado-oab-nuvem/main/questoes_nuvem.json)
* **Manifesto de Versões:** [manifesto_nuvem.json](https://raw.githubusercontent.com/juarezbruschijunior/simulado-oab-nuvem/main/manifesto_nuvem.json)

## 🚀 Como Funciona a Atualização no Celular:
Quando uma nova prova da FGV/OAB (como o 48º Exame) for adicionada a este repositório, todos os aplicativos instalados nos smartphones dos alunos baixarão e liberarão as novas questões automaticamente ao serem abertos!
